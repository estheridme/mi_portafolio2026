# Guia del proyecto: Trabajo colaborativo con Git

Documento para un companero que nunca vio este proyecto.

## Descripcion

Proyecto del Laboratorio 03 donde se practico el trabajo colaborativo con Git y GitHub.

### Que incluye

- Repositorio con ramas
- Commits descriptivos
- Uso de pull requests

## Instalacion y uso

1. Clonar el repositorio con `git clone`
2. Entrar a la carpeta del proyecto con `cd`
3. Crear una rama nueva para trabajar
4. Subir los cambios con push
